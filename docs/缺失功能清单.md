# SimpleNote 缺失功能清单

> 基于对项目全部代码的审阅，按照功能领域分类，列出当前版本中尚未实现但对笔记应用有实际价值的功能点。按**重要性**和**实现难度**分级。

---

## 一、核心笔记功能

### 🔴 高优先级

| # | 功能 | 现状 | 说明 | 实现复杂度 |
|---|------|------|------|------------|
| 1 | **笔记搜索** | 无 | 侧边栏笔记数量多时（>50 条）无法快速定位。建议至少支持标题搜索，理想情况下支持正文全文搜索 | 低 |
| 2 | **文件夹 / 标签分类** | 扁平列表 | 所有笔记平铺在一个列表中，无层级组织。支持至少一级文件夹或标签 | 中 |
| 3 | **置顶 / 收藏笔记** | 无 | 无法将重要笔记固定在列表顶部，目前仅按更新时间排序 | 低 |
| 4 | **导出笔记** | 无 | 无法将笔记导出为独立文件。建议支持导出为 `.md`、`.html` 或 `.pdf` | 低~中 |
| 5 | **导入笔记** | 无 | 无法从外部（如 Markdown 文件、其他笔记工具）导入笔记 | 低 |
| 6 | **笔记字数 / 字符数统计** | 无 | 编辑器底部无统计信息，无法了解笔记长度 | 极低 |

### 🟡 中优先级

| # | 功能 | 说明 | 实现复杂度 |
|---|------|------|------------|
| 7 | **排序方式切换** | 目前仅按"最近更新"排序。应支持按创建时间、标题字母序、手动拖拽排序 | 低 |
| 8 | **多选 / 批量操作** | 批量删除、批量导出、批量移动到文件夹 | 中 |
| 9 | **笔记模板** | 创建新笔记时可选择模板（如会议纪要、周报、代码笔记） | 低 |
| 10 | **笔记固定 ID 路由友好** | 当前 URL 使用 UUID（`/note/a1b2c3d4-...`），不利于分享。支持自定义短链接或 slug | 中 |

## 二、Markdown 编辑体验

### 🔴 高优先级

| # | 功能 | 现状 | 说明 | 实现复杂度 |
|---|------|------|------|------------|
| 11 | **常用 Markdown 工具栏** | 无 | 缺少粗体、斜体、标题、列表、链接、图片、代码等快捷按钮。目前用户需要手写所有 Markdown 语法 | 低 |
| 12 | **代码语法高亮** | 纯文本 | Markdown 代码块无高亮显示。集成 highlight.js 或 Prism.js 即可大幅提升阅读体验 | 低 |
| 13 | **粘贴图片自动上传** | 仅支持文件选择 | 用户在编辑器中 `Ctrl+V` 粘贴剪贴板图片时，应自动上传并插入 Markdown 链接 | 中 |
| 14 | **Marked.js GFM 配置** | 默认配置 | 未启用 GFM（GitHub Flavored Markdown）。缺少表格对齐、任务列表、删除线、自动链接等常用语法 | 极低（一行配置）|

### 🟡 中优先级

| # | 功能 | 说明 | 实现复杂度 |
|---|------|------|------------|
| 15 | **自动生成目录 (TOC)** | 根据 Markdown 标题层级自动生成可跳转的目录 | 中 |
| 16 | **快捷键插入** | `Ctrl+B` 粗体、`Ctrl+I` 斜体、`Ctrl+K` 链接、`Ctrl+Shift+1`~`6` 标题等 | 低 |
| 17 | **查找与替换** | 在编辑器内 `Ctrl+F` 查找、`Ctrl+H` 替换 | 中 |
| 18 | **支持 Mermaid 图表** | 在 Markdown 中嵌入流程图、时序图等（` ```mermaid `） | 低（引入 mermaid.js） |
| 19 | **支持 LaTeX 数学公式** | `$...$` 或 `$$...$$` 数学公式渲染 | 低（引入 KaTeX） |

### 🟢 低优先级

| # | 功能 | 说明 |
|---|------|------|
| 20 | **Emoji 快捷输入** | 输入 `:emoji:` 自动联想或提供 Emoji 选择面板 |
| 21 | **任务列表勾选交互** | 预览区的任务列表 checkbox 可点击切换 |
| 22 | **代码块一键复制** | 代码块右上角添加"复制"按钮 |

## 三、UI / UX 体验

### 🔴 高优先级

| # | 功能 | 现状 | 说明 | 实现复杂度 |
|---|------|------|------|------------|
| 23 | **手动主题切换** | 仅跟随系统 | CSS 中已有 `dark` 主题变量，SVG 中有 `moon-fill.svg` 和 `brightness-high-fill.svg` 图标暗示了此功能的设计，但实际代码中没有实现。用户无法在运行时手动切换主题 | 低 |
| 24 | **移动端预览模式** | 被强制禁用 | `checkMobileView()` 在 ≤768px 时固定为 `editor-only`，用户在移动端永远看不到预览。应允许用户手动切换 | 极低（删除一行代码）|
| 25 | **保存失败自动重试** | 无 | 网络异常时仅显示提示，不自动重试。应实现指数退避或定时重试 | 低 |
| 26 | **笔记自动备份 / 快照** | 无 | 误删或错误保存无法恢复。建议定期创建本地快照文件（如 `backups/{id}/{timestamp}.txt`） | 中 |

### 🟡 中优先级

| # | 功能 | 说明 | 实现复杂度 |
|---|------|------|------------|
| 27 | **视图偏好记忆** | 记住用户上次使用的视图模式（编辑/预览/双栏），刷新后恢复 | 低 |
| 28 | **侧边栏折叠宽度记忆** | 记住侧边栏展开/折叠状态 | 低 |
| 29 | **全屏编辑模式** | `F11` 或按钮触发全屏专注编辑模式（隐藏侧边栏和工具栏） | 低 |
| 30 | **笔记列表无限滚动 / 虚拟滚动** | 笔记数量 >200 条时 DOM 节点过多影响性能 | 中 |
| 31 | **笔记拖拽排序** | 支持在侧边栏中手动拖拽调整笔记顺序 | 中 |
| 32 | **快捷键帮助面板** | `Ctrl+/` 或 `?` 弹出所有快捷键列表 | 低 |

## 四、数据与安全

### 🔴 高优先级

| # | 功能 | 现状 | 说明 | 实现复杂度 |
|---|------|------|------|------------|
| 33 | **笔记版本历史** | 无 | 每次保存覆盖上一版。建议在 `meta.json` 中增加版本快照机制，或定期将 `.txt` 复制到 `history/` 目录 | 中 |
| 34 | **笔记加密** | 无 | 敏感笔记应支持 AES 加密存储（密码派生密钥），打开时解密 | 高 |
| 35 | **多用户支持** | 单密码 | 仅支持一个全局密码。建议支持多个用户账号（用户名+密码），每个用户独立的笔记空间 | 高 |
| 36 | **API 访问令牌** | 无 | 除 Cookie 认证外，支持 Bearer Token 便于脚本/API 调用 | 中 |

### 🟡 中优先级

| # | 功能 | 说明 |
|---|------|------|
| 37 | **笔记分享（只读链接）** | 生成带 Token 的只读分享链接，无需登录即可查看 | 中 |
| 38 | **WebDAV 同步** | 支持通过 WebDAV 协议与第三方同步工具（如 Obsidian、Syncthing）同步 | 高 |
| 39 | **跨设备同步** | 通过云端（如 S3、WebDAV、或自建 sync server）多设备同步 | 高 |
| 40 | **自动备份到 Git** | 将 `notes/` 目录初始化 Git 仓库，每次保存自动 commit | 中 |

## 六、实现优先级建议

### 第一阶段（快速提升，工作量小）

```
#1 笔记搜索          → 纯前端实现，对侧边栏 DOM 做过滤
#4 导出笔记          → 后端加一个 /api/notes/:id/export 接口
#11 Markdown 工具栏  → 前端加一排按钮，调用 document.execCommand 或手动包裹
#14 GFM 配置         → marked.setOptions({gfm: true, breaks: true})
#23 主题切换         → 加一个按钮切换 data-theme 属性
#24 移动端预览       → 移除 checkMobileView 中的强制逻辑
#25 保存重试         → 前端加 setTimeout 重试
#41 Docker Health    → compose 加 healthcheck 配置
#44 优雅关闭         → main.go 加信号监听
```

### 第二阶段（中等工作量）

```
#2 文件夹/标签       → meta.json 加 folders 字段，前端加文件夹 UI
#5 导入笔记          → 前端加文件选择，后端解析 .md 文件
#12 代码高亮         → 引入 highlight.js
#13 粘贴图片         → 监听 paste 事件，读取 Clipboard API，上传
#16 快捷键插入       → 监听 keydown，手动包裹选区
#26 自动备份         → saveNoteContent 中定期写入 backups/
#33 版本历史         → save 时旧内容写入 history/ 目录
#37 分享链接         → 生成带 hash 的只读 URL
```

### 第三阶段（较大工作量）

```
#34 笔记加密         → AES-256-GCM 加密存储
#35 多用户           → meta.json 加 users 字段，每个用户独立 store
#38 WebDAV           → 集成 WebDAV 服务端
#39 跨设备同步       → Conflict-free 同步机制
```
