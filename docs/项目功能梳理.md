# SimpleNote 项目功能梳理

## 一、项目概述

SimpleNote（简单笔记）是一个基于 **Go + Gin** 构建的轻量级 Markdown 在线笔记应用。它以单二进制文件的形式提供，部署简单，开箱即用，适合个人或小团队在本地/服务器上快速搭建私人笔记服务。

- 项目地址：`github.com/BaoPaper/SimpleNote`
- 开发语言：Go 1.25+
- Web 框架：Gin v1.11
- 协议/渲染：前端 Markdown 实时渲染（Marked.js + DOMPurify）

## 二、核心功能清单

### 2.1 笔记管理

| 功能 | 说明 | 实现位置 |
|------|------|----------|
| **创建笔记** | 通过侧边栏「+ 新建笔记」按钮创建，自动生成 UUID，默认标题"新建笔记" | `handlers_notes.go:73` / `store.go:105` |
| **编辑笔记内容** | 实时 Markdown 编辑，支持纯文本输入与实时预览 | `note.ejs` 前端 JS |
| **自动保存** | 输入防抖 300ms 后自动保存内容，标题防抖 500ms 后自动保存 | `note.ejs` 前端 JS |
| **手动保存** | 支持 `Ctrl+S` 快捷键手动触发保存 | `note.ejs` 前端 JS |
| **笔记重命名** | 直接点击标题输入框修改，自动同步到侧边栏列表 | `handlers_notes.go:102` |
| **删除笔记** | 侧边栏每条笔记悬停显示 `×` 删除按钮，删除前有 confirm 二次确认 | `handlers_notes.go:88` |
| **笔记列表** | 侧边栏展示全部笔记，按"最近更新时间"倒序排列 | `store.go:360` |
| **切换笔记** | 点击侧边栏笔记项，通过 AJAX (`/api/notes/:id/content`) 无刷新加载 | `handlers_notes.go:41` |
| **空库自动初始化** | 首次访问首页时若笔记为空，自动创建一条空白引导笔记 | `store.go:39` / `handlers_auth.go:65` |

### 2.2 Markdown 渲染

| 功能 | 说明 |
|------|------|
| **实时渲染** | 编辑区与预览区并排显示，输入即时渲染 Markdown |
| **内容净化** | 使用 DOMPurify 对渲染后的 HTML 进行净化，防止 XSS 注入 |
| **支持的语法** | 标准 Markdown 语法：标题、列表、代码块、表格、引用块、图片、链接等 |
| **视图切换** | 支持「编辑 / 预览 / 双栏」三种模式切换（移动端自动为单栏） |

### 2.3 附件上传

| 功能 | 说明 | 实现位置 |
|------|------|----------|
| **文件上传** | 最大 10MB 限制，通过工具栏上传按钮选择文件 | `handlers_notes.go:135` |
| **文件存储** | 上传文件以 `UUID + 原扩展名` 重命名后存入 `uploads/` 目录 | `handlers_notes.go:152` |
| **自动插入 Markdown** | 上传成功后在光标位置自动插入 Markdown 语法链接 | `note.ejs` 前端 JS |
| **智能区分图片** | 图片格式（jpg/png/gif/webp/svg/bmp）自动生成 `![]()` 图片语法 | `handlers_notes.go:170` |
| **附件追踪** | 保存笔记时自动解析正文中的附件引用，删除笔记时同步删除附件文件 | `store.go:208-216` |
| **附件清理** | 编辑笔记移除附件引用后，旧附件文件会被自动清理 | `store.go:210-215` |

### 2.4 用户认证

| 功能 | 说明 | 实现位置 |
|------|------|----------|
| **密码登录** | 单密码认证机制，密码通过环境变量 `PASSWORD` 配置 | `handlers_auth.go:21` |
| **JWT Token** | 使用 HS256 签名 JWT，存于 `auth_token` HttpOnly Cookie | `auth.go:61` |
| **记住我** | 勾选后 Token 有效期为 30 天；未勾选为 1 天 | `auth.go:62-65` |
| **Cookie 安全** | `HttpOnly: true`、`SameSite: Strict` | `handlers_auth.go:35-47` |
| **登录页访问控制** | 已登录用户访问 `/login` 自动跳转首页 | `handlers_auth.go:11` |
| **登出** | 清除 Cookie 并跳转登录页 | `handlers_auth.go:51` |
| **路由级鉴权** | 受保护路由统一通过 `requireAuth` 中间件校验 | `auth.go:12` |
| **401 响应** | API 请求返回 JSON 错误；浏览器请求自动重定向到登录页 | `auth.go:16-20` |

### 2.5 响应式 UI / UX

| 功能 | 说明 |
|------|------|
| **桌面端布局** | 左右分栏（侧边栏 + 编辑/预览区），带窗口边框样式 |
| **移动端适配** | 768px 以下侧边栏变为抽屉式，通过汉堡菜单触发 |
| **侧边栏遮罩** | 移动端点击遮罩区关闭侧边栏 |
| **深色模式** | 自动跟随系统 `prefers-color-scheme: dark`，使用 CSS 变量切换主题 |
| **保存状态指示** | 保存后显示"已保存"绿色提示，保存失败显示红色错误提示 |
| **笔记排序** | 保存成功后笔记自动置顶（最近更新优先） |
| **键盘快捷键** | `Ctrl+S` 手动保存 |
| **友好删除** | 鼠标悬停笔记项才显示删除按钮，避免误操作 |

### 2.6 错误处理

| 功能 | 说明 | 实现位置 |
|------|------|----------|
| **统一错误渲染** | `renderError` 方法支持同时对 HTML 和 JSON 请求返回合适响应 | `errors.go:5` |
| **HTTP 401** | 密码错误 → 密码错误页 | `handlers_auth.go:25` |
| **HTTP 404** | 笔记不存在 → 笔记不存在页（附返回首页按钮） | `handlers_notes.go:22` |
| **HTTP 405** | 请求方式不支持 → 自定义 405 错误页 | `router.go:55` |
| **HTTP 500** | 服务器错误 → 通用错误页 | `errors.go:17` |
| **Panic 恢复** | Gin CustomRecovery 中间件捕获 panic 并渲染错误页 | `router.go:15` |
| **错误自适应** | API 请求返回 JSON 错误信息，浏览器请求返回 HTML 错误页 | `errors.go:6-29` |

### 2.7 数据存储

| 功能 | 说明 | 实现位置 |
|------|------|----------|
| **文件系统存储** | 笔记内容以 `{uuid}.txt` 纯文本文件存储在 `notes/` 目录 | `store.go:349` |
| **元数据管理** | `notes/meta.json` 存储笔记 ID、标题、创建/更新时间、附件列表 | `models.go:34` |
| **附件目录** | 附件存放在 `uploads/` 目录，独立于笔记内容 | `models.go:47` |
| **并发安全** | `sync.Mutex` 保护所有读写操作，防止多协程数据竞争 | `models.go:45` |
| **旧数据迁移** | 首次启动自动将旧版 `1.txt ~ 8.txt` 编号笔记迁移为 UUID 格式 | `store.go:245` |

### 2.8 部署与运维

| 功能 | 说明 |
|------|------|
| **单二进制部署** | `go build` 后只需二进制 + `public/` + `views/` 即可运行 |
| **环境变量配置** | `PASSWORD`、`JWT_SECRET`、`PORT`、`JWT_SESSION_EXPIRES_IN`、`JWT_REMEMBER_EXPIRES_IN` |
| **Docker Compose** | 一键启动，支持卷映射持久化数据 |
| **多架构交叉编译** | CI 支持 Linux (amd64/arm64/mipsle)、macOS (amd64/arm64)、Windows (amd64) |
| **Release 自动发布** | 推送 `v*` Tag 自动触发 Release 工作流，自动生成 Release Notes 与 SHA256 校验 |
| **Docker 镜像构建** | 推送 `main/master` 分支自动构建 Docker 镜像推送到 GHCR |
| **基础镜像优化** | 使用 Alpine 3.22 运行时 + Tini 作为 PID 1 |
| **Tini 信号转发** | 正确处理容器停止信号，避免僵尸进程 |

## 四、环境变量说明

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `PASSWORD` | string | `password` | 登录密码 |
| `JWT_SECRET` | string | **必填** | JWT HMAC 签名密钥 |
| `JWT_SESSION_EXPIRES_IN` | duration | `1d` | 未勾选"记住我"的 Token 有效期 |
| `JWT_REMEMBER_EXPIRES_IN` | duration | `30d` | 勾选"记住我"的 Token 有效期 |
| `PORT` | string | `3000` | 服务监听端口 |

**有效期格式支持**：`数字 + 单位`，支持单位：`ms`、`s`、`m`、`h`、`d`、`w`、`y`。

## 六、技术栈详情

### 后端
- **Go 1.25** — 编译型语言
- **Gin v1.11** — HTTP 路由与中间件框架
- **golang-jwt/jwt/v5** — JWT 签发与验证（HS256）
- **google/uuid** — 笔记与附件唯一 ID 生成

### 前端（原生，无框架）
- **Marked.js** — Markdown → HTML 解析
- **DOMPurify** — HTML 净化（XSS 防护）
- **EJS** — 服务端模板渲染
- **CSS 变量 + `prefers-color-scheme`** — 自动深浅色主题

### 基础设施
- **GitHub Actions** — CI/CD（测试 → 构建 → Release）
- **Docker / Docker Compose** — 容器化部署
- **Alpine Linux + Tini** — 最小化运行时

## 八、亮点特性总结

1. **极简部署** — 单二进制文件 + 零数据库依赖，开箱即用
2. **数据自主** — 所有笔记以明文文件存储，用户完全掌控数据
3. **实时预览** — 编辑即预览，所见即所得
4. **XSS 防护** — DOMPurify 净化渲染输出
5. **自动保存** — 防抖保存，不怕意外丢失
6. **附件智能管理** — 自动插入 Markdown 链接、自动清理无用附件
7. **响应式设计** — 桌面/移动端自适应，深浅色主题自动切换
8. **无感迁移** — 自动兼容旧版数据格式
9. **多平台发布** — 一键发布到 7 种平台架构
10. **容器就绪** — Docker Compose 一键部署，GHCR 镜像自动构建
